## 0. 最優先の依頼

これまで `sim_compare` で調べてきた声門断面幾何・剥離・圧力の改善を **simulation-mainの通常計算へ直接導入する**。過去版はGit履歴から戻せるので、今回は `legacy/new` の切替スイッチ・旧手法の重複保持・診断用別ソルバーを作らない。

決定済みの新仕様：

1. **断面探索を全面更新**：左右それぞれの変形後内側表面を三角形化し、実座標 `x=const` 平面との交線から同じ物理AP座標 `z` の対向ギャップを求める。旧 `j` 列単独線分と `preferredSegment` の方法は廃止する。
2. **断面積・粘性用の幾何量を全面更新**：`A(x)=∫max(h(x,z),0) dz`、`G3(x)=∫max(h(x,z),0)^3 dz`。正のギャップ区間は線形補間とゼロ交差を正しく扱う。欠損と接触を混同しない。
3. **最狭断面・剥離位置を新しい断面列から決定**。基準の `flowSeparationAreaRatio=1.0` は変更しない。すべての処理で同じ断面列・剥離位置を使う。
4. **流体の粘性抵抗 `Rv` は入口から剥離位置まで**積分する。剥離より下流を含めない。慣性項 `Lg`、非線形損失 `Rk`、音響回路の時刻更新は今回変更しない。
5. **剥離後の壁面圧力は `Psep` のまま一定**：`x >= xSep` の節点・流路圧力 `p(x)=Psep`。`Psep→Pd[0]` のsmoothstepブレンドを廃止し、下流圧 `Pd[0]` に置き換えない。剥離位置手前は従来のBernoulli＋粘性圧力式を維持する。
6. **通常の実行方法を一切変更しない**。ユーザーは従来どおりビルドディレクトリから `./simulation ../input/param.txt`（従来の `./simulation` 起動方法があればそれも維持）で実行する。フル連成計算はCodexが自動で回さない。

**実装時に変更してよい物理コードは既存の `src/**/*.cpp` のみ**。`include/`、`CMakeLists.txt`、`input/param.txt`、既存テスト、Pythonツール、スクリプト、出力仕様の大規模改変は禁止。必要な補助構造体・ヘルパー関数は既存 `.cpp` 内の無名namespace等へ実装する。新しい `.h`、新クラス階層、新しい設定項目は原則作らない。

## 3. 新しい断面の幾何計算

### 3.1 x平面と3D内側表面の交差

1. `geom.surfp[i][j]` を使い、`i=0..nsurfl-1`、`j=0..nsurfz-1` の全内側面を参照する。4頂点の面を2三角形へ分ける。右側を左側の鏡映で代替せず、両側の `State::disp` を独立して使う。
2. 各時刻の変形後頂点座標を使い、各物理平面 `x=x_k` と三角形の交線分 `(y,z)` を求める。頂点一致・辺一致・ほぼ平行な三角形も許容差付きで扱う。
3. 各 `(x_k,z)` における左右それぞれのy交点候補を得る。共有頂点/共通辺由来の重複は除去する。異なる枝が複数ある場合は隠さず数える。正常な湾曲によって交点が複数ある場合は、既存診断の内側包絡線ルールを参考に、実際に向かい合う内側のyを選ぶ。
4. `gapSign` の向きに従って `h_signed=gapSign*(y_right-y_left)`、`h_open=max(0,h_signed)` を求める。負の `h_signed` は接触・重なりの情報として保持し、欠損点をゼロギャップにしてはならない。
5. 違う連結成分を無理につなぐ、断面の欠損を補間する、z方向に折り返した多価の輪郭を何の警告もなく1枝へ置換する処理は禁止する。正常な複数交点は内側包絡線を一意に定められる場合だけ使用する。

### 3.2 断面位置・計算負荷

- 既存の全AP共通x上限による制限をやめ、狭窄候補x≈11〜12 mmを含める。
- 対象のkawahara_mesh7_soft形状では、まず **x=0〜10 mmを0.5 mm間隔（21平面）＋x=10〜13 mmを0.05 mm間隔（後続60平面）＝計81平面**を採用する。これは現行入力形状向けの数値分割であり、形状が範囲を覆わない場合に存在しない表面を補外しない。
- AP位置は共通の物理zサンプル（初期目安0.1 mm間隔）。既存 `ChannelSections` の `x,area,gapCubed,valid` を最終結果として埋める。下流の `FlowModel` 等が使う構造と単位は維持する。
- 静的な三角形接続や作業配列を可能な範囲で再利用し、`全三角形×全平面×全z` の無駄な再探索を避ける。OpenMPや外部ライブラリの新規導入、大規模な高速化フレームワーク追加はしない。
- `ChannelSections::resize()` が既に持つ旧material-`sigma`／初期狭窄ログは新方式で使用しないなら削除・無効化するか、ログを実装どおりに訂正する。実際に使っていないアンカーを「保持済み」と表示しない。

### 3.3 AとG3の積分・AP欠損の扱い（重要）

```text
h(x,z) = gapSign * (yRight_inner(x,z) - yLeft_inner(x,z))
hOpen(x,z) = max(0, h(x,z))
A(x)  = ∫ hOpen(x,z)   dz        [mm²]
G3(x) = ∫ hOpen(x,z)^3 dz        [mm⁴]
```

- 共通の物理zに沿って積分する。各区間で線形変化するhの正部分のみを厳密に積分し、符号が変わる場合はゼロ交差位置で分割する。円滑に負ギャップを正面積へ変換してはいけない。
- **下流では両側表面のAP被覆が減る**。したがって今回の形状に対して実装する面積は、両面が観測できる連続AP区間での **「内側面間の観測面積」**であり、端部まで含めた全気道の厳密な断面積ではない。この近似をソースコメントと簡潔な起動ログで明示する。
- 欠損領域をゼロギャップとして加算すること、穴を飛び越えて台形積分すること、勝手にAP端部の形状を外挿することは禁止。複数の不連続な有効区間があれば区間ごとに積分し、形状の多価性・被覆率を確認する。
- 観測できるAP長が急減したためだけの「偽の最狭」を正解として採用しないこと。最低限、参照APスパンに対する各xの被覆率を調べ、**十分な被覆のない断面は最小面積探索の候補から除外**する。まず目安90%を採用し、境界に最小値が張り付く場合には `coverage_limited` と明記する。90%は探索用の便宜的な採否条件であり、物理的な全断面積を保証しない。
- どのx区間でも十分なAP被覆が得られない場合は、架空の断面を作らず、理由を表示して明示的に終了する。検査用に大規模な解析を追加する必要はない。
- 参考：`sim_compare/results/plane_gap_refinement/comparison.md` には観測断面・固定AP断面等の違いが整理済み。これらを無断で混合して「全断面積」と呼ばない。

## 4. 最狭位置・剥離判定と積分範囲

- 各時刻、同じ `sections.x/area/gapCubed/valid` に対して `selectSeparationByAreaRatio()` を実行する。
- 検索対象は入口から連続的に有効な断面だけ。無効な中間断面をスキップして先の位置の面積とつなげない。`Amin` は正・有限な開口と正しく区別された閉鎖として求める。
- `flowSeparationAreaRatio=1.0` で最狭断面が剥離点となる現行方針を維持する。比が1より大きい場合は最小面積から下流方向に最初に比を満たす位置を選ぶ。後続がなく比に達しない場合は既存の `usedFallback` を正しく記録する。
- **処理順を変更する**：断面を構築 →最狭・剥離選択 →新しい断面と剥離情報に基づき流量と`Rv`を更新 →圧力を生成 →表面荷重をモード投影する。
- `include/` を編集しないため、`FlowModel::advance()` の引数を増やせない場合は、`src/fluid/flowModel.cpp` 内で同じ `selectSeparationByAreaRatio()` を同じ `sections`・同じ比・同じ閾値で呼ぶ。**別の剥離ロジックを複製しない**。`forceCalculatorFluid.cpp` で得た選択と同一になることを小さな実装assertで確認するか、同じ共有関数の使用を徹底する。
- 粘性項：
  `Rv = 12 μ ∫[x_in,x_sep] dx / G3(x)`（SI単位に正しく変換）。区間離散化は現行の台形相当の端点平均ルールを再利用し、区間 `[i-1,i]` の右端が `sepIndex` 以下の場合だけ加算する。未定義区間をスキップして抵抗を過小にしない。
- **`Lg` は現行通り全有効流路区間の積分**、`Rk` は最小断面積、`beta`・`alpha1`・`alpha2` は従来のPs依存係数を使う。既存のNewton反復式と音響回路 `Pu/Uu/Pd/Ud` 更新順は変えない。
- `area<=kAreaClosedMm2` の閉鎖と、面切断の欠損や無効値とは別状態。`Ug=0` にするのは実際の閉鎖分岐だけ。新方式で無効・非有限・非単調xが出た場合は時刻/断面番号/理由を示して停止し、`0`・前時刻値・後端断面でごまかさない。

## 5. 剥離後の圧力はPsep一定（今回の明示変更）

剥離手前：現在の `forceCalculatorFluid.cpp` のBernoulli差分と粘性による圧力降下、圧力回復時の抑制分岐を維持する。

開放時に剥離断面で計算された圧力を `Psep = psurf[sepIndex]` と置き、**それより下流では値を変えない**：

```text
x < xSep        : 従来式で計算した断面圧力を物理xで補間
x = xSep        : p_wall = Psep
x > xSep        : p_wall = Psep
i > sepIndex    : psurf[i] = Psep
```

- `Psep` の正負に関係なく一定とする。`Psep=0`、`Psep=Pd[0]` と仮定せず、負圧を勝手にクリップしない。
- **smoothstep / `flowBlendLengthMm` は壁面圧力の計算から除去**する。剥離位置で圧力を連続に保ち、下流に向かって勾配をゼロにする。表面節点の実座標xを使った上流補間は維持する。
- **音響回路の下流状態 `Pd[0]` はそのまま別に保持する**。今回は壁面負荷のモデルだけ変更する。`Pd[0]` に `Psep` を代入したり、声道の境界条件を変更したりしない。このため壁面圧と声道内圧が一致しない場合があり、今回のモデル仮定として受け入れる。
- 既存閉鎖分岐では `Ug=0` の扱いと、`Psep` を閉鎖断面でどう定義するかを一貫させる。現行の閉鎖分岐（閉鎖断面圧は下流圧）を最小限維持してよいが、その下流も**その時点のPsep一定**とし、未初期化値を使用しない。
- `lastBlendEndX_` や `separation.dat` の従来列は破壊せず、ブレンドがなくなったことが明確な値（例えば `x_blend_end=x_sep`）を記録する。意味のない「ブレンド区間」を残さない。
- 左右の壁面圧力には同じ `xSep` と `Psep` を用い、既存の変形後面積ベクトルから力を与える。
