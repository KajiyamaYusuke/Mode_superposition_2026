> 作成: 2026-10-29 / 対象: 3D左右Body 12/6 kPa・Cover 3/3 kPa・声門下圧900 Pa

## 0. 目的・今回の問い

**左Body=12 kPa、右Body=6 kPaと右を柔らかくしたのに、代表点では右の振幅が小さい（右/左振幅比 \(A_R/A_L=0.302\)）理由を、測定定義・モード寄与・流体仕事・減衰・接触・幾何の順に切り分ける。**

この現象を即座に「硬い側が流体から多くエネルギーを得た」と説明しない。単純な静的コンプライアンス \(A\propto1/k\) は、固有モードと流体・接触を介して連成する自励振動へそのまま適用できない。

主要仮説（**診断前の仮説**）:

- **H0 計測・条件の違い**: 過去の0.302と現在の解析は条件、代表点、符号、評価窓、右Cover=2/3 kPaが異なる。
- **H1 観測点依存**: 右のモードの節位置、局所形状、モード同士の相殺のため、代表点のみ小さく見える。
- **H2 流体入力の左右差**: 共通の駆動圧であっても壁面荷重・位相が異なり、右の主要モードへの正味仕事が小さい、または負である。
- **H3 散逸・接触**: 右の構造減衰、接触による拘束または仕事が振幅に影響する。
- **H4 幾何・数値問題**: 表面格子、AP順序、要素反転、荷重補間、モード正規化、収束不良が見かけの振幅差を作る。

**優先順は H0 → H1 → H2 → H3/H4。原因が一意に決まらなければ未判定で終了する。**

## 3. 第一段階: 「振幅比0.302」を同じデータから検算

### 3.1 代表点と符号

- `simulation.cpp` の代表点選択を読み、**元の左右対応点のID、初期座標(x,y,z)、AP位置、表面格子(i,j)** を取得する。現在のmainではモニター候補(x,z)=(9.2,8.5) mmへの最近接点探索があるが、過去の0.302が**同一観測点**かは未確認。
- `displace.dat` の `uyL_mm`、`uyR_mm` を用いるとき、これらが絶対位置でなく初期形状からの変位であることをコードと出力で確かめる。右側の鏡映処理・開口方向の符号も点検。
- 開口方向は実際の初期gapの正方向から判定する。正しい `signGap` を使い、例えば \(\Delta g=s_g(u_{y,R}-u_{y,L})\) と定義。左右の変位振幅は符号を変えても不変だが、**位相・流体仕事・開口力の符号には影響する**。
- 頻度や正負の符号で代表点を意図せず入れ替えていないことを確認。複数の近接点で感度も示す。

### 3.2 必須指標（左右・時間窓を同時に計算）

- 半ptp \(A_{\rm ptp}=(u_{\max}-u_{\min})/2\)、平均変位、中央値、標準偏差、平均を差し引いたRMS、P95–P5の半幅、局所周期ごとのピーク振幅（十分な周期検出が成立する場合のみ）。
- **毎回 \(R/L\) の方向を明記**して、半ptp比、RMS比、P95–P5比を算出。分母ゼロ、信号振幅不足、変動が強い窓には品質フラグを付ける。
- 0.30–0.50 sの再計算比が0.302と一致するか、どの観測点・窓・物理条件で再現したかを示す。異なれば原因を表形式で比較し、H1以降の説明に進まない。
- 時間波形とサイクルごとの変化を示し、変動の大きい波形を「定常」と呼ばない。FFTの最大ピークをただちに基本周波数または1:2同期の証明にしない。

### 3.3 「代表点の小振幅」か「右声帯全体の小振幅」か

保存VTUまたは再構成に必要なモード時系列から、左右対応する表面節点について **同一評価窓の半ptp、RMS、AP方向分布** を比較する。AP端の拘束・接触と中央を分ける。データが粗い場合は時間分解能を明記して概算に止める。

右の代表点のみ小さく、他の領域では大きい場合は「全体として右が振動しにくい」と結論しない。

## 4. 第二段階: モード形状・合成変位の寄与

モード番号は**現行実装での選択モードindexと元COMSOLのsource mode番号を両方記録**。旧データと連番を無条件に同じとみなさない。左右別に各モードの周波数を取得する。

観測点p、側s、モードmについて:

\[
u_{s,m}^{probe}(t)=C_{\rm unit}\,\phi_{s,m,y}(p)\,q_{s,m}(t),\quad
u_s^{probe}(t)=\sum_m u_{s,m}^{probe}(t).
\]

現行 `State::mode2uf` には \(q\phi\) をmmの幾何座標へ換算する `1e3` がある。**実装上の座標・変位単位を確認してから**値を比較する。左/右で座標とモードの鏡映符号が対応しているか検証。

- 左右**全使用モード（通常20）**の代表点寄与：半ptp、RMS、時間平均、\(\phi_y(p)\)、\(\operatorname{var}(u_m)\)、合成時の共分散を計算。
- \(\mathrm{var}(\sum_m u_m)=\sum_m \mathrm{var}(u_m)+2\sum_{m<n}\mathrm{cov}(u_m,u_n)\) により、モード間の**観測点での打消し**と、そもそもの寄与の弱さを切り分ける。これはエネルギー移送の証明ではない。
- 代表点変位の再構成値が保存 `displace.dat` と一致するか、最大絶対/相対誤差を提示。元と異なるモード選択やVTUを混ぜない。
- 左右の主要寄与モードの \(\phi_y\) をAP方向に可視化。観測点が節付近か、別モードの符号・位相により相殺しているかを確認。
- 第1・4・5モードに限定せず**20モードを集計**し、報告の図は寄与上位5＋必要な比較モードへ絞る。旧Kanaya診断の100モード前提を持ち込まない。

### 5.1 離散仕事の定義・検算

流体圧力を正負に分類した一般化力 \(Q^+,Q^-\) と、各モードの \(q_n,q_{n+1}\) を同じ荷重評価ステップで対応づける:

\[
\Delta W_{s,m,n}^{fluid}=Q_{s,m,n}^{fluid}\,(q_{s,m,n+1}-q_{s,m,n}),\qquad
Q^{fluid}=Q^++Q^-.
\]

実際の使用荷重が時間積分のどの段階で評価されたかをコードで確認。**異なる時刻の \(Q_n\) と \(\dot q_{n+1}\) の積を厳密な仕事として扱わない。** 正圧・負圧での仕事の符号は圧力符号とは無関係であり、\(Q\,\Delta q\) の符号で判断する。

\[
D_{s,m}\simeq\sum_n c_{s,m}\dot q_{s,m,n}^2\,\Delta t,\quad
c_{s,m}=2\zeta_s\omega_{s,m}
\]

は**実積分器のモード質量・減衰係数・時刻規約を確認**して使用。非負性、構造減衰に相当する値であること、単位を記録。必要なら中点/台形などの求積誤差感度を併記。

流体仕事の生値は平均位置への移動分を含む。**\(W_{\mathrm{fluid,raw}}\)、基準一定荷重による \(W_{\mathrm{static}}=Q_{\mathrm{ref}}(q_b-q_a)\)、差 \(W_{\mathrm{dynamic}}\) を区別**。\(Q_{\mathrm{ref}}\) は根拠のある平衡/基準値だけ使用し、単なる時間平均を「平衡力」と断定しない。周期端点が近い窓も比較し、窓・基準の取り方に敏感なら励振/減衰の判定を保留する。

### 5.2 観測対象

- 左右それぞれ全使用モード: \(q,qdot\)のRMS、\(W^+,W^-,W_\mathrm{fluid,raw},W_\mathrm{dynamic},D_\mathrm{struct}\)、対応する固有周波数、\(\Delta q\)。
- 主要寄与モード: \(q(t),\dot q(t),Q_\mathrm{fluid}(t),Q_\mathrm{contact}(t)\)、累積流体仕事と減衰、一般化力と速度の位相関係。
- 流体荷重: `pressure.dat` の圧力値ではなく、**実際に各壁面節点へ与えた最終的な流体荷重**を正負圧に分解し、左右・流路x位置・AP端/中央で集計。\(F_x,F_y,F_z\) と開口方向成分の符号を保持。
- 接触: **最終採用した**接触反復の荷重と接触ペア数、侵入量、AP端/中央、中央部開閉との時間関係。接触ペナルティの仕事を一括して「散逸」と呼ばない。接触力の評価時刻が流体荷重と違う場合は明記。
- モードエネルギーの独立性は自明ではない。正規化モードのGram行列の非対角項を確認し、SI/J表記の整合が未検証の場合は「離散仕事の代数値」「相対比較」と明記する。

### 5.3 必須の数値整合性

1. \(\sum \mathbf f^++\sum \mathbf f^-=\sum \mathbf f^{fluid}\)（左右・成分別）。
2. \(Q_m^++Q_m^-=Q_m^{fluid}\)、および実際の総採用一般化力が流体＋接触の分解と一致。
3. \(\sum_m Q_{m,n}^{fluid}\Delta q_{m,n}=\sum_i\mathbf f_{i,n}^{fluid}\cdot\Delta\mathbf u_{i,n}\) を**同一荷重・同一節点・同一モード数・SI変位**で検算。mm↔m換算とモード符号に注意。
4. 仕事の正負分解・区間和が全時間積分と一致。\(D\ge0\)、非有限値なし、二重計数なし。
5. 既存 `consistency.csv` / `run_metadata.json` と突き合わせる。検算NGなら物理機構の解釈を止め、数値問題として報告する。閾値は既存診断の相対 \(10^{-8}\)＋絶対床等を参照し、変えるなら正当化する。

## 6. 第四段階: 接触・幾何・数値安定性の品質ゲート

- 声門最小断面積、流量、\(P_g\)、剥離位置、左右中央gap、接触ペア数/貫入量を**同じ時刻・同じ窓**に並べ、代表点振幅との関係を見る。
- **AP端の常時接触**と中央部の実際の接触を分ける。接触率や「面積ゼロ率」を局所的な接触荷重と同一視しない。
- 出力VTUでAP z順序反転、四面体符号付き体積、極端な変形を確認。保存時刻しかなければ「全ステップ異常なし」と主張しない。
- 表面NAS検出格子と指定寸法の不一致警告、左右対応付け、時間刻み・モード数の収束性は**既存ログを先に調査**。新しい収束試験を勝手に大量実行しない。
- 以前の大圧力条件でAP順序反転停止があった事実は、900 Paでも同じ異常が起きたことを意味しない。対象条件自体で評価する。

## 9. 判定基準と最終報告で回答すべき質問

| 仮説 | 支持を考える条件（例） | 限界 |
|---|---|---|
| H0 | 元条件・観測点・窓の違いで0.302が再現しない | 観測不一致を物理要因へすり替えない |
| H1 | 代表点で右が小さいが表面全体では差が弱い、または主要モード寄与が相殺される | 代表点だけで全体の振動エネルギーは分からない |
| H2 | 検算済み同一窓で右の主要モードへの動的流体仕事が相対的に小さい/負 | 過渡・基準力・モード正規化・連成の影響 |
| H3 | 接触時刻/領域や構造減衰が左右差と一貫して対応する | 仕事だけでは原因と結果が区別できない |
| H4 | モード/節点再構成・力/仕事整合・幾何品質に不一致がある | 物理説明を保留し数値問題を先に修正 |

`report.md` は必ず以下に**数値または「未測定」**で回答:

1. 0.30–0.50 sの\(A_R/A_L=0.302\)は**どのrun・観測点・条件**で再現できたか。0.10 s刻みの別窓とRMS比でも傾向は同じか。
2. 右声帯全体でも振幅が小さいか。それとも代表点の節・モード相殺による局所的な現象か。
3. 代表点への主要モード（左右別の元モード番号、固有周波数、変位寄与）は何か。右ではどの項が相殺しているか。
4. 左右のモード別流体仕事（正負圧、raw/dynamic）・構造減衰・接触参考仕事はどう違うか。**入力された仕事が大きいことと振幅の大きさを混同していないか**。
5. AP端接触・局所gap・幾何学的異常は関与していそうか。整合性チェックは通ったか。
6. 最も支持される説明は何か。未確定なら、次に行うべき**最小の追加確認1件**は何か。

判定は **「確認済みの観測事実」「支持する証拠のある機構候補」「未判定」「数値検証失敗」** に分ける。**強い剛性差で複雑波形が出たことと、本件の振幅比の原因説明は別の主張**である。単一runだけで剛性差の因果効果を確定しない。
