## 1. 目的・全区間で計算することの厳密な定義

- 評価時間は**`[0.50,1.00) s`**で固定。方法ごとに区間選択を変えない。
- 各方式の検出イベントの時刻列`t_1<...<t_M`を**評価窓内で全件**使用する。隣接間隔は`T_i=t_{i+1}-t_i`、`i=1,...,M-1`。
- **流量ゼロが一度もない時期を挟んで、次にゼロとなった場合も、その2回のゼロ到達間隔をそのまま1個の`T_i`として計上する。** 他の方式も同様：長い/短い間隔を「周期外」「不自然」「ACF不一致」「low-shape-corr」「形状変化」「1.45T超」等として削除しない。
- **隣接イベント間隔を複数の人工周期へ分割しない。** `T_i`が2倍・3倍に相当しても、`T_i`のまま保存・Jitterに算入。これは厳密には基本振動周期と異なる場合があるので、レポートでは**イベント間隔ベースのJitter**と表現する。
- **全窓のイベントを使うとは「時間窓内に存在しないイベントを予測して埋める」意味ではない。** 閉鎖なし・閾値未到達時はイベントなし。その結果生じた長い間隔も計算に含める。
- **新主値では`segment`の境界を設けず、境界を理由にJitter/RAP/PPQ5の差項を捨てない。** 自動的に決まった最長区間のみ／観測限定・高信頼限定のみの値を主値にすることは禁止。
- 端点`0.50`/`1.00`はイベントが存在する場合だけ採用。イベントが窓外なら、端点へ架空のイベントを作って区間を埋めない。`[0.50,1.00)`を歩査したことと「物理的な全時間を周期で埋めた」ことを混同せず、最初/最後のイベント時刻を報告。
- 自己相関`T0(t)`を探索の補助・診断に使うのは可。ただし`T0`に合わせてイベントをスナップ・間引き・補完・統合・強制分割しない。強制的な共通`pulse_id`は不要。7方式はそれぞれ別のイベント列でよい。
- **「全区間・全イベントJitter」`J_all_detected`を主値**として出し、旧`pooled_v2`や`global-cycle`は「参考・旧定義」と明確に区別。旧主値を新名称で上書きしない。

## 3. 7種類の独立イベント定義

**基本は各方法それぞれの局所極値・下降交差という「観測された事象」を拾うこと。** 複数ピークがあり実在する場合、基本周期に合わないという理由で削らない。ただし全ての1標本の微小な数値揺らぎを「物理的なピーク」と断定する必要はない。ノイズ床やピーク検出の基本規則が必要なら**両剛性比で事前に同じ固定ルール**を使い、その候補数と除外数を記録。後からJitterを小さくするための調整は禁止。

| key | 元信号 | 独立したイベント |
|---|---|---|
| `Ug_max` | `Ug` | 各局所極大の実時刻 |
| `Ug_min` | `Ug` | 各局所極小の実時刻 |
| `Ug_zero` | `Ug` | 正流量から0へ下降して**ゼロ領域に入り始めた時刻** |
| `Ug_3pct` | `Ug` | 局所流量ピーク`Upeak`の3%への下降交差 |
| `Ug_10pct` | `Ug` | 局所流量ピーク`Upeak`の10%への下降交差 |
| `Amin_max` | `Amin` | 最小断面積波形の各局所極大 |
| `Amin_min` | `Amin` | 最小断面積波形の各局所極小 |

### 3.1 流量・面積の極大・極小

- `find_peaks(Ug)`・`find_peaks(-Ug)`、`find_peaks(Amin)`・`find_peaks(-Amin)`相当の既存処理を再利用。
- **複数の実在する極大/極小を、同じ「振動の1周期」だという先入観で一つに統合しない。** 候補が多いこと自体が、イベント時刻間隔Jitterに反映され得る。
- ハード条件`rho>=0.65`、`T/T0∈[0.55,1.65]`、位相系列best score、強いpeak prominence、一周期一極大のルールなどで**全イベントからピークを選り分けない**。既存global-cycleのDPは新主Jitterのイベント選別器として使用しない。
- 必要最低限の一定ノイズ床、サンプル上の反転の定義、plateau判定、補間ON/OFFは記録。ピークの候補一覧は保存。検出器規則の誤差感度は`0～低い固定閾値`等の比較数値として出してよいが、ケースごとにチューニングしない。
- 面積極小がゼロでplateauなら**1つのplateauを1イベント**とし、代表時刻（開始/中央/終了）のルールを固定。感度は数値のみでもよい。通常の極値は従来の3点放物線補間を使用してよい。
- **ゼロ流量のplateauで`Ug_min`が一つの局所極小として定義できない場合**は、plateauを1イベントとして時刻定義を明記。`Ug_zero`は必ずplateau**開始**。
- サブサンプル補間を用いてもイベント数を勝手に変更しない。

### 3.2 `Ug_zero`（主試行、特に重要）

- **`Ug`が0になった区間**を抽出する。主規則は`Ug==0`または数値実装上厳密なゼロとして表現されたサンプル。`Ug>0`から`Ug<=0`へ入る下降側の最初のサンプル/交差をイベントとする。
- 非負クリッピングや小さな負値・浮動小数点丸め誤差がある場合、主規則をデータ実態に合わせ**冒頭に明記**。`Ug<0`を単純に何回も跨ぐ場合はゼロ領域の連続ランを1回と数える。
- **ゼロが10サンプル続いても1イベント**。再開して正流量となり、再びゼロとなったら新しいイベント。
- ゼロ到達が一定期間存在しない場合も、**その前後のゼロ到達時刻の差をそのまま1周期間隔**として採用する。途中の波形を無視してその区間を削除しない。
- ただし数値的に0でない微小流量を**主値のゼロ到達と偽装しない**。必要なら`|Ug|<ε`の近ゼロ版を別キー（`Ug_near_zero_sensitivity`）の感度解析として数値のみ保存。主結果に混入させない。
- 観測ゼロイベントが`M<3`など少ない場合、指標が定義できる/できないを数式どおりに判定。無理にイベントを増やさない。

### 3.3 `Ug_3pct`、`Ug_10pct`

- **各局所ピーク`Upeak>0`の3%/10%に対する下降交差**を、当該ピークから次の局所谷までの実波形の下降枝で探す。基準は`Uθ=θ Upeak`（0m³/s基準）、谷～山の振幅比ではない。
- 複数峰が存在しても**基本周期に合わせて主峰へ集約することを禁止**。局所ピークごとに「有効な下降交差があるか」を独立にチェック。複数の局所極大があり、各々に別の実下降交差があれば、それぞれのイベントを記録。
- **同じピークから反跳によって複数回交差する場合**：事前固定のルールとして「そのピークに続く谷へ向かう下降枝上の最後の下向き交差」を主とし、最初の交差・全交差の時刻と件数も`candidate_crossings.csv`に数値記録。ただし別ピークと同じ交差を重複割当しない。前後の枝の区切りは局所谷で定義し、`T0`から決めた1周期窓では切らない。
- **実際に閾値へ到達しない場合はeventなし**。前後の検出イベントの時刻差をそのまま`T_i`にする。`Upeak`の後の極小で代用した時刻を`Ug_3pct`の「観測された交差」として混入させない。
- 実サンプル2点の符号反転・大小関係から時刻を線形補間。隣接標本ID、実流量、補間係数を記録。0への到達時刻も必要なら同様に確定。
- 「ピークが多い」ことと「1ピークから同じ閾値を振動で複数回横切る」ことを区別し、イベント数が不当に膨れないことを検証。閾値の定義は全条件共通。

## 4. Jitter / RAP / PPQ5の主集計を単一イベント列で統一

各方法・各剛性比について、`[0.50,1.00)`にある採用イベント時刻`t_1<...<t_M`を重複を除いて**すべて**連結（時間だけ昇順）し、`T_i=t_{i+1}-t_i`（`i=1,...,N=M−1`）を作成。

### 4.1 数式（全N間隔を使う、例外除外なし）

\[
\overline T = \frac1N\sum_{i=1}^{N}T_i,\quad
\mathrm{Jitter}_{local} =
\frac{\frac1{N-1}\sum_{i=1}^{N-1}|T_{i+1}-T_i|}{\overline T}\times100.
\]

\[
\mathrm{RAP} =
\frac{\frac1{N-2}\sum_{i=2}^{N-1}\left|T_i-\frac{T_{i-1}+T_i+T_{i+1}}3\right|}{\overline T}\times100.
\]

\[
\mathrm{PPQ5} =
\frac{\frac1{N-4}\sum_{i=3}^{N-2}\left|T_i-\frac{T_{i-2}+T_{i-1}+T_i+T_{i+1}+T_{i+2}}5\right|}{\overline T}\times100.
\]

- Jitterは`N>=2`、RAPは`N>=3`、PPQ5は`N>=5`で定義。満たさないとき`NaN/NOT_DEFINED_INSUFFICIENT_EVENTS`。**0として保存しない**。
- **1つの`t`列からN間隔を全件使用する。`N_J=N−1`、`N_RAP=N−2`、`N_PPQ5=N−4`を必ず自己監査**。旧処理の`pooled_v2`集計に通さない。
- 信頼度の低さ、ピークの多峰性、想定`T0`の何倍か、時間帯、前後半、極大/極小の違いによる除外禁止。極端な`T_i`もそのまま寄与する。
- `T_i`の最小/最大、平均、標準偏差、イベント数、`mean_frequency`（診断目的）、`max(T_i)/median(T_i)`、`T_i/T0(t_i)`の診断は保存してよい。ただし診断値を採否判定へフィードバックしない。
- 「各`Ji`」は`J_i=|T_{i+1}-T_i|/\bar T ×100`（`i=1,...,N−1`）。**全項の時刻を対応付けて保存**。単一`J_i`をその時間帯に固有の「局所Jitter」と誤称せず、`period_pair_jitter_contribution`等に命名。
- Jitter値が大きい特定時間を除外して別の主値を作ること禁止。**前半/後半は補助的な独立再集計**とし、全窓主値を置き換えない。
- 検出時間の被覆率は「最初のイベント〜最後のイベント」等**計算式を明記した参考指標**として記録。全窓でイベント候補を走査したかのcoverageと、イベントが実在した時間の割合を混同しない。**イベントが途切れた部分をゼロ被覆として捨てた集計にはしない**。

## 6. 入出力の整理・高速実装

**既存実装の流用優先**。`tools/analyze_airflow_metrics.py`にあるファイル読み込み・極値候補・線形/放物線補間・閾値交差・Jitter/RAP/PPQ5・CPP/図出力の関数を調査し、使えるものをそのまま使う。

- ソルバは**一切変更しない**。既存の`global-cycle`、`closure-threshold-and-area`等は非破壊のlegacyモードとして残せるなら保持し、**新しい`--tracking-method all-events`等**で本仕様を呼び出す。
- データの入力・イベント抽出・全イベント集計・図出力を分離。7方式は**独立にイベント抽出して、同じ集計関数へ流す**。共通パルス列/DP/ACFを新しい`all-events`主解析に誤適用しない。
- 生時刻`t=step×dt`を厳守。各閾値交差はサンプル2点から線形補間、極値は既存の必要な補間が可能。生時刻/補間時刻/元データindexを保存。
- データ量は0.5s×20kHz程度なので、**大がかりな新クラス構造・GPU・別ライブラリを導入しない**。可能な限り単一スクリプトで実装し、簡単な合成テストを追加。コーディング時間を増やす大量の追加解析/閾値探索は求めない。
- 推奨CLI（実際の既存引数名に合わせて可）：

~~~bash
python3 tools/analyze_airflow_metrics.py \
 --input analysis_runs/manual_run_archive/r0p25_P900_20261104T064537_9fba0102/snapshot/dat/airflow_vt.dat \
 --area-input analysis_runs/manual_run_archive/r0p25_P900_20261104T064537_9fba0102/snapshot/dat/area.dat \
 --dt 1e-5 --start 0.50 --end 1.00 --case-id r0p25 \
 --tracking-method all-events --closure-thresholds 3,10 \
 --out-dir analysis_runs/jitter_all_events_20261107/results/r0p25
~~~

- 面積ファイルが実在しない場合は、流量5方式を解析して`MISSING_AREA_INPUT`を表示。ただし他run/別物性/別時間の`area.dat`で補わない。

## 7. 必須の合成テストと新旧の差異検証

1. **既知の不規則イベント列**：全イベントの隣接`T`がJitter/RAP/PPQ5へ100%入り、異常に長い`T`や短い`T`も計上。`N−1`、`N−2`、`N−4`項数をチェック。
2. **多峰波形**：局所極大を複数持つ場合、`Ug_max`は実在する両極大を保存（事前固定した数値ノイズ除外以外）。`T0`との不一致による除外0件。
3. **ゼロ到達と非閉鎖**：連続0 plateauを1イベント、非閉鎖期間はイベントなし、次のゼロとの長い間隔を**1個の間隔としてJitterに使用**。
4. **3%/10%独立**：複数の局所ピークと各下降枝を検証。閾値に届かなければeventなし、後続の実イベントまでの間隔を集計。反跳時の定義、同交差の二重割当禁止。
5. **面積48列最小値**：元CSVから定義どおり算出、極大・極小で独立イベント列を得る。
6. **窓端**：`[start,end)`のみを使い、イベントを仮想の窓境界に置かず、窓外イベントへの補完なし。
